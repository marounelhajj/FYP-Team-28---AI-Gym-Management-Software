# Sprint 4 demo script (Fitness Zone, FYP Group 28)

The full Sprint 4 demo: every story that is Done in Sprint 4, grouped by role so
there are only six logins. The video is silent; each story has a caption with
its Jira key, title, role and one sentence.

```bash
npm install                     # once, at the repo root (Playwright)
npm run demo:seed:full          # fresh demo database: demo/.data/demo.sqlite3
npm run demo:record:full        # records demo/sprint4-demo-full.mp4 (+ .webm)
```

Record **right after seeding**: the coach's live class and the class that needs
a substitute are placed a couple of hours after the seed runs. Seed and record
mid-month (the pay period and the feedback month are calendar months). Logins
are generated by the seed and written only to `demo/.data/credentials.json`.
`--only=coach,rec,member,bm,mkt,gm` records some roles; `--headed` shows the
browser.
