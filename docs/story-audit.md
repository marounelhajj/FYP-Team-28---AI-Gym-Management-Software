# Story audit: Sprints 1 to 4

Every story marked **Done** in Jira for Sprints 1 to 4, checked against the code on `main` on 2026-11-24 (after the open at-risk PRs #36 to #40 and #41 were merged).

For each story we read the acceptance criteria and comments in Jira, found the backend and frontend code, ran its tests, and checked each criterion. Each Partial or Missing verdict was then checked by a second reviewer, who tried to find the missing code before agreeing.

- **Built**: present, tested and working.
- **Partial**: present, but a criterion, the UI or the tests are missing (the gap is listed).
- **Missing**: no implementation.

**At audit time: 57 Built, 11 Partial, 4 Missing** (72 stories).

The "Now" column shows the state after the follow-up PRs from this audit.

> Jira note: the sprint ids 35 (Sprint 1) and 68 (Sprint 2) no longer return any issues. The 30 Done stories from those sprints now carry only the future "Sprint 5" label, so they are listed here as "Sprint 1-2". Please check the board, since the closed sprints seem to have been removed.
